# Chromalith — Weave the Light

A slide-and-route light-beam puzzle. Drag rows and columns to shift mirrors,
prisms and mixers, routing colored beams into every crystal — in its exact
color. 1000 procedurally generated, verified-solvable levels across 10 biomes.

## Play

Web: https://elchinjabbarli.github.io/chromalith/

## Mechanics

- Colors are RGB bitmasks; beams mix additively (red + green = yellow…).
- Sources emit fixed beams; crystals must be lit with their exact color.
- Rows and columns slide cyclically; fixed devices never move.
- Mirrors bend, splitters double, prisms split white into channels, mixers
  merge, filters pass only their color.

## Tech

- TypeScript + Canvas + WebAudio (no image or audio assets — everything is
  drawn and synthesized in code).
- 1000 levels generated by reverse construction and verified by an
  independent test (all solvable; par 2–14).
- Capacitor-ready for iOS (appId `com.elchinjabbarli.chromalith`).

## Scripts

- `npm run build` — regenerate levels, typecheck, bundle to `docs/`
- `npm run test:levels` — verify all 1000 levels
- `npm run icons` — regenerate icons and OG image

Version: 1.0.0 (kept in sync across package.json, capacitor.config.ts,
src/version.ts and docs/levels.json by scripts/check-version.mjs)
